# Sepehr Ebrahimi

B.Sc. Electrical Engineering, Amirkabir University of Technology (Tehran Polytechnic), 2026.

My interests are **wireless communications**, **RF and antenna design**, and **control systems**. The repositories below are my course projects and B.Sc. thesis. Each one has an English report with results, figures, and a check against theory where one exists.

**Tools:** MATLAB / Simulink, Python, C++, VHDL, Ansys HFSS, Keysight ADS, GNU Radio, Webots, Git.

## Thesis
| Project | Summary |
|---|---|
| [lte-v2x-simulation](https://github.com/sepehrebrahimi004/lte-v2x-simulation) | Link- and system-level MATLAB simulation of the four architectural challenges of the LTE-V2X sidelink (Doppler, synchronisation, MBMS, resource allocation), with new solutions: a two-stage CFO estimator and a Hungarian-algorithm scheduler |
